### 2.2. 마을에서 연 뿌리 (봄: A 마을 뿌리 ネイピア商会·アーモロード)

짜임과 자리는 미궁과 같다. 다른 곳은 셋이다.
- 장소 띠에 장소 이름(「ネイピア商会」「アーモロード」)이 나온다.
- 그림 창에 그 장소 그림(가게 안·도시)이 나온다.
- 시설 안에서는 SAVE 단축이 없고 OPTION만 있다.

### 2.3. 대원 고르기 (봄: C, A 둘)

STATUS·EQUIP·CUSTOM을 고르면 뿌리가 그대로 남는다.
- 고른 명령 줄이 밝은 하늘색이 되고, 커서는 아래 파티 카드로 간다.
- **커서가 있는 카드 하나만** 노란 테두리(약 4px)를 두른다. 다른 카드는 테두리가 없다.
- 물음 글(「누구의 …」)은 없다.

보고만: 확인하면 그 대원의 화면이 열리고, 취소하면 명령 목록으로 돌아간다. 하위 화면에서는 L·R로 앞·다음 대원으로 간다. III HD의 SKILL은 하위 목록에서 「スキル」을 고른 뒤 같은 방식으로 대원을 고른다.

### 2.4. 하위 목록 (봄: B BOOK)

BOOK을 고르면 BOOK 줄이 하늘색이 되고, 목록 오른쪽에 「クエスト · ミッション · ギルドカード」 세 줄이 뜬다.
- 하위 목록의 마지막 줄이 BOOK 줄 높이에 맞는다(x 약 412~735, y 372~538).

보고만: III HD의 SKILL은 「スキル · リミット」 두 줄이다. 영어판 II의 ITEMS는 「Inventory · Valuables」이고, 이것은 낮은 해상도 그림에서만 보았다.

### 2.5. 명령이 여는 것 (보고만)

조사 보고 §4의 요약이다. 그림 이름이 내용과 다른 것이 있어 조정자가 확인하지 못했다. 하위 화면을 고칠 때 다시 확인한다.
- → research 08(2026-10-25)이 상태·소지품·장비·스킬 트리를 프레임으로 확인했다. 아래 요약과 다른 곳은 08을 따른다(예: 상태에는 탭이 보이지 않는다).
- **ITEM**: 왼쪽에 목록(「ITEM 12/60」), 오른쪽에 「使う · 捨てる」, 아래에 설명.
- **SKILL**: 필드에서 쓰는 스킬(회복 등)의 목록. 대상은 아래 카드에서 고른다.
- **STATUS**: 위에 「[L] 이름 [R] Lv」, 탭 셋(ステータス · クラス・スキル · リミットスキル), 오른쪽에 큰 초상.
- **EQUIP**: 왼쪽에 장비 칸 넷과 능력치 미리보기, 오른쪽에 가방 목록(못 끼는 줄은 어두운 붉은색), 아래에 장비 설명.
- **CUSTOM**: 스킬 트리(SKILL POINT, 직업 탭, 레벨 1~10 미리보기).
- **PARTY**: 전열·후열 바꾸기.
- **BOOK**: III은 퀘스트·미션·길드 카드, I·II는 도감과 퀘스트다. 열리기 전에는 흐리다.
- **OPTION**은 설정 창을, **SAVE**는 중단 세이브 확인 창(YES·NO)을 연다.

## 4. 제안

작은 것 → 중간 → 그림이 필요한 것 차례다.

**작은 것** (그림 없음, 캠프 코드와 07 §9.7만 고친다):
- **P1. 대원 고르기 표시.** 모든 카드의 노란 테두리를 없애고, 커서 카드에만 노란 테두리를 두른다(원작).
- **P2. 명령 차례.** 있는 명령을 원작 차례로 놓는다: 소지품(ITEM) · 상태(STATUS) · 장비(EQUIP) · 스킬(CUSTOM) · 기록. 숫자 키도 그 차례를 따른다.
- **P3. 맨 위 띠.** 설명 띠를 장소 띠(「시험 층 / B1F」 꼴)로 바꾸고, 오른쪽 위에 소지금을 둔다. 다이얼 자리의 층 문패는 걸음만 남기거나 장식 다이얼로 바꾼다.
  - 명령 설명은 원작처럼 없앤다.
  - 대원 고르기의 물음 글도 없앤다. 노란 테두리가 대신한다.
  - 알림(오류 등)은 장소 띠 아래 짧은 줄로 옮긴다.

**중간**:
- **P4. 바탕을 원작 무늬 판으로.** 불투명 청록 격자에 덩굴 무늬를 벡터로 그리고, 굽은 그림 창(III 모양)을 둔다.
  - 층 그림이 생기기 전(M3)에는 그림 창 안에 지금 3D 시야를 비춘다. 그림 대신 실제 시야를 쓰는 것을 원작과 다른 점으로 적는다.
  - 바탕이 불투명해지면 시야를 어둡게 하던 층(`CAMP_DIM`)은 뿌리에서 필요 없다. 하위 화면은 따로 본다.
- **P5. 명령 일곱 줄은 지금 들어가지 않는다.**
  - 64px 줄로는 명령 목록 위 끝(116)과 방향 십자(511) 사이 395px에 다섯 줄까지만 들어간다. 다섯 줄은 344px이고, 일곱 줄은 64 × 7 + 6 × 6 = 484px다.
  - 원작처럼 없는 기능을 흐린 줄(SKILL·PARTY·BOOK)로 두려면 키패드나 줄 크기를 다시 정해야 한다.
  - 그래서 그 기능(필드 스킬, 대열 바꾸기, 퀘스트)이 생길 때 정한다. 그때까지는 다섯 줄을 유지한다.

**그림 필요** (M3):
- **P6. 그림 창 안의 그림.** 층 그림과 마을·시설 그림이 필요하다. 마을 메뉴(R4 S4)도 같은 틀을 쓴다.
- **P7. 그림 창 안의 표시.** 채집 횟수는 채집(M3)이 생기면 더한다. 시계·날짜는 달력 규칙이 없으니, 만들지 않으면 원작과 다른 점으로 남긴다.

## 5. 사용자가 정할 것

1. 고칠 범위:
   - 작은 것(P1~P3)만;
   - 작은 것과 바탕(P1~P4);
   - 지금 그대로.
2. 명령 이름: 지금처럼 한국어로 할지, 원작처럼 영어 글자(ITEM · STATUS …)로 할지.
3. 설명 띠: 원작처럼 없애고 장소 띠로 바꿀지(P3), 장소 띠 아래에 한 줄로 남길지(원작과 다른 점).

→ **2026-10-25 사용자 결정(D26)**:
- 범위는 작은 것과 바탕(P1~P4)이다.
- 명령 이름은 한국어 그대로다.
- 설명 띠는 원작처럼 장소 띠로 바꾸고, 알림만 띠 아래 짧은 줄로 보인다.

## 6. 한계와 남은 확인

- **그림 이름**: 조사 에이전트가 붙인 이름 가운데 둘이 내용과 다르다.
  - `yt_eo3hd_10_labyrinth_equip_screen`은 장비 화면이 아니라, 마을(アーモロード)에서 EQUIP을 고른 뒤의 대원 고르기다.
  - `yt_eo3hd_12_labyrinth_camp_skill_sublist`는 SKILL 하위 목록이 아니라, 미궁에서 CUSTOM을 고른 뒤의 대원 고르기다.
  - 그래서 §2.5의 하위 화면과 SKILL 하위 목록은 보고만이다. 하위 화면(상태·장비·스킬 트리·소지품)을 원작과 다시 견줄 때 프레임부터 다시 확인한다.
- **해상도**: 프레임은 동영상 재생 화면이라 색과 1~2px 크기는 근사다.
- **흐림 규칙**: PARTY·BOOK이 언제 흐린지는 보고만이다.
- **영어판**: ITEMS 하위 목록과 뿌리의 필드 효과 표시(「Beast Bell 27 TURN」)는 낮은 해상도 그림에서만 보았다.
- **조사 중 문제**: 조사 에이전트의 프레임 캡처 스크립트(헤드리스 Chromium)가 2시간 넘게 멈췄다. 조정자가 그 프로세스를 끄고 가진 프레임으로 마무리하게 했다. 빠진 프레임은 영어판 셋이다.
