## 작성 경위

- 2026-10-16, Paseo Codex 에이전트 2개(gpt-6-astra, 추론 max, Speed=Fast)가 웹 검색·원문 열람으로 조사했다.
- 에이전트의 파일 쓰기가 실패(`auto-review` 모드)해 최종 응답 전문을 조정자가 그대로 옮겨 저장했다. 본문은 고치지 않았다.
- 각 항목의 확인 상태(직접 읽음 / 검색 결과 요약만 봄 / 미확인 / 추정)는 문서 안의 표기를 따른다. 게임 실행이나 수치 재현 시험은 하지 않았다.

## 쓰는 방법

- 원작 사실과 설계 제안이 문서 안에서 구분되어 있다. 기획에서 원작 수치를 쓸 때는 「추정」 표시를 함께 옮긴다.
- 원작 고유 명칭(직업·스킬·지명·몬스터)은 조사 식별용으로 적었다. 게임에서 오마주로 이어 쓸 명칭은 기획 문서(`docs/design/04-world-and-art-direction.md` §2.4)에서 정한다.
